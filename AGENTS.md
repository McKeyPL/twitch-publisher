# Repository instructions

- Write code, comments, user-facing application text, and commit messages in English.
- Commit each completed, coherent change separately. Use a concise Conventional Commit subject and a body explaining what changed and why.
- Treat the installation's config.yaml as the source of truth for runtime settings. Preserve local settings during unrelated edits.
- Keep credentials, OAuth tokens, databases, recordings, logs, and runtime backups out of commits. Stage only the files needed for the change.
- Verify code changes using the relevant tests before committing. Do not restart the running publisher or Copyright Guard as part of repository maintenance.
